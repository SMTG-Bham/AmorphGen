# Heavy transition-metal dioxide validation set

Amorphous models of the heavy 4d/5d transition-metal dioxides (MO₂), generated
to validate AmorphGen's `rutile_dioxide` packing class. These dense
rutile/CaCl₂-type oxides pack far more tightly than light oxides, so they use a
higher packing factor (0.66) than the generic `metal_oxide` class (0.52). The
class is assigned geometrically (MO₂ with a 4+ cation radius below the
rutile/fluorite cutoff, ~0.70 Å), so it also covers light rutile dioxides
(TiO₂, SnO₂, …) while excluding fluorite dioxides (ZrO₂, HfO₂, CeO₂); see
`PACKING_FACTORS`, `_RUTILE_DIOXIDE_RMAX`, and `_classify_compound` in
`amorphgen/utils/radii.py`.

## Contents

Each `*.vasp` file is a single amorphous MO₂ cell (M₈O₁₆, 24 atoms), species-
sorted POSCAR (VASP5), Direct coordinates.

| System | Amorphous ρ (g/cm³) | Crystal ρ (g/cm³) | vs crystal | M–O (Å) | M coord. |
|--------|--------------------:|------------------:|:----------:|:-------:|:--------:|
| MoO₂   | 5.81 | 6.47  | −10% | 2.09 | 6.0 |
| RuO₂   | 6.08 | 6.97  | −13% | 1.98 | 5.1 |
| RhO₂   | 6.19 | ~7.2  | ~−14% | 1.98 | 5.1 |
| WO₂    | 9.78 | 10.8  | −9%  | 2.13 | 6.4 |
| ReO₂   | 9.95 | 11.4  | −13% | 1.99 | 4.8 |
| OsO₂   | 10.13 | 11.4 | −11% | 1.98 | 4.8 |
| IrO₂   | 10.23 | 11.67 | −12% | 2.03 | 5.4 |
| PtO₂   | 10.37 | ~10.2 | ~+2% | 2.04 | 4.8 |

Amorphous densities, mean M–O bond lengths, and mean metal coordination are
calculated from the bundled cells using `StructureAnalyser` with
`cutoff="auto-rdf"`. The densities are about 9–14% below the tabulated crystal
values except for PtO₂, which is about 2% above its approximate reference.
Mean M–O bond lengths span 1.98–2.13 Å and mean metal coordination 4.8–6.4.

From the repository root, inspect an individual cell with:

```bash
amorphgen --analyse examples/validation/heavy_tm_dioxides/IrO2.vasp \
    --cutoff auto-rdf
```

## How these were generated

The cells were generated by random placement (auto density from the
`rutile_dioxide` class) followed by a fixed-cell MACE relaxation. This command
uses the same workflow; without the original random seed and software versions
it does not reproduce the bundled coordinates:

```bash
amorphgen --random-gen --composition "IrO2*8" -n 1 --relax \
    --model mace-mpa-0 --device cpu --dtype float32 \
    -C none -f 0.05 --opt-steps 300 \
    --format vasp -o iro2_run
```

`-C none` fixes the cell during relaxation. Placement can still expand the
cell on a retry under the default `--retry-mode expand`. To hold the initial
density during placement as well, choose `--retry-mode reduce-minsep` or
`--retry-mode none`. A hybrid anneal-and-quench workflow can sample further
atomic rearrangements; its MD ensemble and final cell filter determine
whether the volume can change.

Crystal densities are tabulated reference values for the rutile/dioxide phases.
